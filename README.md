# AI Resume Analyzer

## About the Project
AI Resume Analyzer is a Python-based web application that analyzes a resume against a job description and provides useful insights.

## Features
- Upload a resume in PDF format
- Calculate resume match score
- Identify matched and missing skills
- Display a skills comparison chart
- Suggest learning topics for missing skills
- Download the analysis report

## Technologies Used
- Python
- Streamlit
- Pandas
- PyPDF
- Scikit-learn

## How to Run
1. Install Python.
2. Install the required packages.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python -m streamlit run app.py
```

## Project Purpose
This project helps users compare their resumes with job descriptions and identify skills they may need to improve.

## Disclaimer
The match score is a basic rule-based estimate and does not guarantee job selection.
